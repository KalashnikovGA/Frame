# Лендинг предзаказа фоторамки

Одностраничный сайт предзаказа: 3D-рамка из дерева со светом снизу, «Послушать» с настоящим звуком и субтитрами на экране рамки, scrollytelling «Как она устроена», интерактив «Думаю о тебе», конфигуратор и форма предзаказа.

Стек: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · three.js + React Three Fiber + drei + postprocessing · GSAP ScrollTrigger · Lenis · Zustand. Шрифты Onest и Cormorant Garamond подключены через `@fontsource`, внешних загрузок нет.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
```

Скопируйте `.env.example` в `.env.local` и заполните при необходимости:

- `NEXT_PUBLIC_YM_ID` — ID Яндекс Метрики (цели: `listen`, `configurator`, `preorder_open`, `preorder_submit`, `think_of_you`);
- `NEXT_PUBLIC_SITE_URL` — адрес сайта для canonical, OG и разметки Product.

### Фото на сайте

Сейчас все фото — временные заглушки с Pexels (лицензия разрешает коммерческое использование): `public/media/web/`, список источников — в `CREDITS.md` рядом. Замените файлы своими с теми же именами или поправьте пути в `MEDIA.web` и `MEDIA.photos` (`src/config/media.ts`).

### Фото (старые заглушки)

Положите `photo-2.jpg` … `photo-6.jpg` в `public/media/` и впишите пути в `MEDIA.photos`. Пока путь `null`, на его месте рисуется тёплая заглушка «фото» (и в 3D, и в CSS-рамках). Лучше 4:3, от 1024×768.

`photo-1.jpg` и `hero-poster.jpg` сейчас сделаны из присланного рендера рамки. `photo-2.jpg` (пара на закате) — нарисованная заглушка: замените настоящим фото пары.

### Аудиоистория

`public/media/story-1.mp3` + `story-1.vtt`. **Сейчас это временная синтезированная озвучка** (офлайн-TTS), чтобы работали звук, субтитры и свечение. Замените на настоящую запись и поправьте тайминги в VTT. Формат реплики: `00:00:04.972 --> 00:00:07.041` и текст. Свет под рамкой считает громкость по реальному звуку через `AnalyserNode`.

### Видео «Как это работает»

Пока видео нет, в секции идёт анимация, нарисованная в коде. Положите `how-it-works.mp4` в `public/media/` и впишите `howVideo: "/media/how-it-works.mp4"` в `src/config/media.ts` — анимация заменится видео.

### Постеры для устройств без 3D

`frame-front.jpg`, `frame-side.jpg`, `frame-night.jpg`, `hero-loop.mp4`: положите в `public/media/` и впишите в `MEDIA.posters` / `MEDIA.heroLoop`. Пока их нет, используются фото продукта и рамки, нарисованные в CSS.

### 3D-модель вместо процедурной

Сейчас рамка строится в коде (`src/three/geometry.ts`: скруглённый корпус с клином, экран 4:3; `src/three/textures.ts`: процедурные волокна дерева). Когда будет готов glTF:

```ts
// src/config/media.ts
frameModel: "/models/frame.glb",
```

Требования к модели: низ в `y = 0`, лицевая сторона смотрит в `+z`, 1 единица = 10 см (10″ рамка ≈ 2,33 × 1,82). Меш с `screen` в имени получит материал экрана с фото и субтитрами, остальные — дерево выбранной породы.

## Предзаказы

Форма шлёт `POST /api/preorder`. Сервер проверяет поля (`src/lib/preorder.ts`, те же правила, что в браузере), пишет в лог и в `data/preorders.jsonl`. Чтобы подключить CRM или платёжный сервис, добавьте функцию в массив `sinks` в `src/app/api/preorder/route.ts`.

На бессерверных хостингах файловая система только для чтения: там запись в файл тихо упадёт, а лог останется. Для продакшена подключите CRM или базу.

## Режимы отрисовки

Выбираются автоматически (`src/lib/caps.ts`):

- **full** — компьютер: отражающий стол, bloom на свете, DPR до 1.75;
- **lite** — телефоны и слабые устройства: без отражений и bloom, DPR до 1.5;
- **static** — нет WebGL или включено «уменьшение движения»: постеры и CSS-рамки, без scrub-анимаций и плавного скролла.

Принудительно: `?mode=full`, `?mode=lite`, `?mode=static`.

Сцены грузятся динамически: первый экран после загрузки страницы, остальные при подлёте к секции. Вне экрана рендер ставится на паузу.

## Одним файлом

```bash
npm run build:single   # → single/ramka.html
```

Весь сайт в одном HTML: код, стили, фото и звук внутри файла, шрифты подгружаются с Google Fonts. Подходит, чтобы показать сайт по ссылке (например, как артефакт claude.ai) или отправить файлом. Форма в этой версии работает как демо, политика конфиденциальности — раздел внизу страницы.
