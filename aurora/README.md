# Aurora

Design-studio-style SaaS landing page hero: full-screen background video, top-left-anchored content, emerald accents.

Stack: Vite · React 19 · TypeScript · Tailwind CSS v4 (`@tailwindcss/vite`) · framer-motion.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build && npm run preview
```

- `src/components/Navbar.tsx` — fixed transparent nav, car logo, "Contact Us" pill
- `src/components/Hero.tsx` — video hero, trusted-by badge, headline, CTAs, social icons
- `public/hero.mp4` — hero background video, from
  `https://pub-1e5b4001b36b47e28e6a2fb775966a79.r2.dev/templates/aurora/hero.mp4`
